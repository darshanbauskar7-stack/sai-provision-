## Features
- **Grocery & Provision Catalog:** 60+ staple items (Grains, Atta, Pulses, Cooking Oils, Spices, Biscuits, Dairy, Hangyo Ice Cream, Soaps, Detergents, Pooja items, Stationery).
- **Interactive Search & Category Filters:** Fast real-time filtering with indicative retail prices in Jalgaon.
- **Digital Kirana Chit (पर्ची):** Interactive grocery order list builder with one-click export directly to WhatsApp (formatted for easy store packing).
- **UPI Payments Section:** PhonePe, Google Pay, BHIM UPI QR code and one-tap copy numbers for Manoj Vasant Bauskar.
- **Multilingual UI:** Instant switcher for English, Marathi (मराठी), and Hindi (हिंदी).
- **Mobile Responsive:** Designed for both smartphones and desktop laptops with zero horizontal scroll or broken layout.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
Production output will be generated inside the `dist/` directory.
